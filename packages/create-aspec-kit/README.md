# create-aspec-kit

Official CLI generator to scaffold a new **aspec-kit** project (Spec-Driven Development with Claude Code & Japanese design docs intake).

## Quick Start

```bash
npx create-aspec-kit my-project
# or
npm create aspec-kit@latest my-project
# or
pnpm create aspec-kit my-project
# or
yarn create aspec-kit my-project
```

## Features

- **Instant Zero-Config Setup**: Downloads the latest template from GitHub repository.
- **Interactive Prompts**: Customizes `.github/CODEOWNERS` with your Steward handle.
- **Auto Clean-up**: Option to keep or automatically wipe the reference sample feature (`000-example-reservation`).
- **Git Ready**: Initializes a fresh Git repository ready for your first feature.
